# Multi-Modal Evidence Review

Welcome to the official documentation for the **Multi-Modal Evidence Review** platform.

This enterprise-grade application uses a combination of powerful Vision-Language Models (VLMs) and deterministic rule engines to automatically evaluate insurance and customer damage claims with near-perfect accuracy and high throughput.

## Features

- **10-Engine Processing Pipeline**: Extracts claims, evaluates image quality, detects fraud flags, enforces evidence standards, and outputs explainable decisions.
- **Enterprise Web Dashboard**: Built with React and Next.js, allowing adjusters and admins to submit claims via a beautiful UI and inspect the AI decision-making process.
- **Mock LLM Mode**: Fully operational local simulated mode allowing the entire application to run and be tested without any API keys.
- **Robust API**: A scalable FastAPI backend perfectly suited for microservice architectures.
